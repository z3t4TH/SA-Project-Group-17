# ข้อมูลร้านที่ใช้ในระบบ

เจ้าของร้านแจ้งเพจ https://www.facebook.com/somtammiangkham และอนุญาตให้ปรับระบบตามร้านนี้ ต่อมาได้ส่งภาพเมนู 2 แผ่นและยืนยันขนาดแล้ว

ข้อมูลสาธารณะที่อ่านจากหน้าเพจวันที่ 27 ตุลาคม 2026:

- ชื่อ: ร้านส้มตำ เมี่ยงคำ
- ที่ตั้งที่เผยแพร่: อ.ทุ่งสง จ.นครศรีธรรมราช (ยังไม่มีที่อยู่ถนน/เลขที่ที่ยืนยัน)
- เวลา: อังคาร–อาทิตย์ 10:30–16:30 น. หยุดวันจันทร์
- โทรศัพท์: 075 421 787
- LINE: https://lin.ee/rMaxkwh

ระบบใช้ชื่อร้านในหน้าลูกค้า หน้าร้าน ชื่อแท็บ เอกสารและรายงาน พร้อมข้อมูลติดต่อในหน้าจอง ใช้ชื่อแบบตัวอักษรและสัญลักษณ์ประกอบของต้นแบบ ไม่อ้างว่าเป็นโลโก้อย่างเป็นทางการของร้าน

ปิดรับการจองวันจันทร์ทั้งในรายการรอบ ทางเลือกเมื่อรอบเต็ม และการบันทึกฝั่งเซิร์ฟเวอร์ ยังจองวันอังคารล่วงหน้าในวันจันทร์ได้ รอบจองยังเป็น 11:00–15:00 น. ตามโครงงาน ซึ่งอยู่ภายในเวลาเปิดร้าน ไม่เปลี่ยนรอบเป็นทุกครึ่งชั่วโมงเอง และไม่ได้ปิดกั้นพนักงานจากงานภายใน/การรับเงินนอกเวลาทำการ

นำเข้าเมนูและราคาจากภาพของเจ้าของแล้ว 157 รายการ/ตัวเลือก เปิดให้สั่ง154 รอยืนยัน3 (ปลาดุกย่าง ซุปหน่อไม้ ไส้กรอก/ไส้อั่ว) ตามเจ้าของแจ้งว่ารอยืนยัน ไม่เดาราคาสามรายการนี้ จำนวนโต๊ะ พนักงาน และธุรกรรมยังเป็นข้อมูลสาธิต และไม่เปลี่ยนฐานข้อมูลสาธิตให้เป็นข้อมูลร้านจริงโดยอัตโนมัติ การจองวันจันทร์ที่อาจเคยบันทึกไว้ก่อนเปลี่ยนกฎจะไม่ถูกลบหรือยกเลิกเอง

แหล่งข้อมูลหลักของโปรไฟล์ในโค้ดคือ `restaurant_profile.py` ไม่ต้องแก้สำเนาข้อมูลหลายจุดเมื่อข้อมูลร้านเปลี่ยน
