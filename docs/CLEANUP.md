ไฟล์ `assets/menu/catalog.json` คัดลอกจากต้นฉบับก่อนย้าย references ทุกชื่อ ราคา และรายการรอยืนยันคงเดิม รูปเมนูต้นฉบับของเจ้าของยังอยู่ใน archive ส่วนภาพประกอบที่มีสิทธิ์แจกจ่ายอยู่ใน assets/menu/images

โปรแกรม MVC เดิมยังใช้ชื่อคลาสเดิมทั้งหมด เพิ่มเฉพาะโมดูล models/presentation.py และ models/menu_images.py และอัปเดตจุดอ่าน catalog ไม่ได้เปลี่ยน schema 20 ตาราง
