## ลิงก์ทดสอบไม่มีรหัสเปิดลิงก์

preview.py เปิดหน้าลูกค้าโดยไม่ใช้ PreviewAccess และไม่สร้าง access_code ใน metadata แล้ว หน้าร้านยังล็อกอิน owner/staff และตรวจ Host/Origin ตามเดิม ตรวจ HTTP ผ่าน handler จริง: /book และ /api/config เปิดได้, /api/state ตอบ 401 เมื่อไม่ล็อกอิน, Host/Origin ที่ไม่ตรงตอบ 403, ล็อกอิน owner/staff ผ่านและ HTTPS cookie มี Secure ชุดทดสอบรวม 73 tests ผ่านใน 14.586 วินาที เบราว์เซอร์ผ่าน Cloudflare เปิดหน้าจองได้โดยไม่แสดงแบบฟอร์มรหัสลิงก์ ไม่มีการรีเซ็ตฐาน Demo หรือ Presentation
