# เครดิตภาพประกอบเมนู

ภาพประกอบสำหรับสาธิต ไม่ใช่ภาพอาหารจริงของร้าน แต่ละรายการใช้คนละภาพ รวมตัวเลือกต่างขนาด บางภาพเป็นอาหารใกล้เคียง วัตถุดิบ สูตร ปริมาณ บรรจุภัณฑ์ และการจัดจานอาจต่างจากเมนูจริง ไม่มีการรับรองร้านจากผู้สร้างภาพ

แต่ละภาพคงสิทธิ์ตาม license ของตน การรวมภาพไว้ใน repository ไม่ได้เปลี่ยน license ของภาพ ส่วน placeholder.svg สร้างสำหรับโครงการนี้
